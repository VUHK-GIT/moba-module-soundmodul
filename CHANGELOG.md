# Changelog

All notable changes are documented in this file.

## 1.0.0 - 2026-08-02

- first stable open-source release;
- autonomous Nano firmware with EEPROM persistence;
- ten hardware inputs;
- BUSY-based playback state detection;
- FIFO queue with duplicate suppression;
- permanent, random and interval automation;
- Windows PureBasic application with German responsive UI;
- automatic and manual COM-port connection;
- PC-session timeout with standalone hardware-input fallback;
- English source-code comments and bilingual documentation;
- MIT source-code license with explicit brand-asset exclusion.
