# Contributing

Thank you for contributing.

- Write source-code identifiers and comments in English.
- Keep the application UI German unless a separate internationalization change
  has been agreed.
- Update both `docs/en/` and `docs/de/` for user-visible behavior changes.
- Do not add the proprietary MOBA-Module logo or icon to forks as branding.
- Run `python scripts/validate.py` before opening a pull request.
- Keep hardware-dependent claims separate from host-side syntax validation.
- Describe the hardware used for every real-device test.

By submitting a contribution, you agree that it is licensed under the MIT
License of this repository.
