# Official brand assets

The official MOBA-Module icon and logo are proprietary assets owned by Sven Häber.
They are **not** licensed under the MIT License.

The public source tree uses a text wordmark by default. An official release may
add the proprietary logo locally and run `python scripts/prepare_ui.py` to embed
it into the generated UI. Its use is governed by
[ASSETS.md](../../../ASSETS.md) and [TRADEMARKS.md](../../../TRADEMARKS.md),
not by `LICENSE`.

Official release builds may additionally use:

- `MOBA_Module_Soundmodul.ico`
- `moba-module_logo.png`

Do not reuse these assets for third-party branding or imply that a fork is an
official MOBA-Module release.
